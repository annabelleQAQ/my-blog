命令行没那么可怕

从 pwd 到 git status，认识几个能帮上忙的小命令。

先知道自己在哪里

终端里的 pwd 会显示当前目录，ls 可以列出目录里的文件。遇到陌生路径，先看清位置，再进行下一步。

一次只做一件事

用 cd 进入文件夹，再用 git status 查看当前仓库的变化。命令不必一下记住，理解它在做什么更有用。

提交前停一下

提交代码前，先运行 git diff 检查改动。不要把密码、令牌或私人信息放进仓库。确认无误后，再用 git add 和 git commit 记录这次进步。
